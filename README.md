# Hi，我是 CandyTek 👋

这里是我制作的一些小工具，主要面向 Android 和 Windows，用来解决日常使用中的小需求。

## 🛠️ 我的小工具

| 项目 | 平台 | 简介 |
| --- | --- | --- |
| [ChinaMetroAtlas · 中国城市地铁线路图](https://github.com/CandyTek/ChinaMetroAtlas) | Android | 离线查看多个城市的地铁线路图，支持地图缩放与在线更新。 |
| [CandyRecorder · 录音工具](https://github.com/CandyTek/CandyRecorder) | Android | 支持多种录音格式，可调整音源、采样率、声道和码率等参数。 |
| [Rotation · 屏幕旋转工具](https://github.com/CandyTek/Rotation) | Android | 强制切换屏幕方向，支持横屏、竖屏、反向显示及自动旋转。 |
| [ScreenTTS · 屏幕朗读工具](https://github.com/CandyTek/ScreenTTS) | Android | 点击控件即可朗读文字，为识字较少的用户提供操作辅助。 |
| [CandyLauncher · 快捷启动器](https://github.com/CandyTek/CandyLauncher) | Windows | 轻量级快捷启动器，支持模糊搜索、拼音匹配和插件扩展。 |
| [cs2-moyu · CS2 摸鱼切换器](https://github.com/CandyTek/cs2-moyu) | Windows | 在玩家死亡后自动切换到指定程序或发送快捷键，下一回合开始时自动切回游戏。 |
| [FileSendApkExport · 文件传输工具](https://github.com/CandyTek/FileSendApkExport) | Windows | 与 Android 端 Apk kit / APK 导出工具配合，在局域网内互传文件，支持多文件传输和拖放。 |
| [SettingsShortcut · 设置快捷方式](https://github.com/CandyTek/SettingsShortcut) | Android | 快速打开常用系统设置项，无需申请任何权限。 |
| [TesterScreenShots · 测试人员截图工具](https://github.com/CandyTek/TesterScreenShots) | Android | 测试人员测试设备时方便截图与分享的小工具，截图并附带日志。 |

欢迎体验，也欢迎在对应项目的 Issues 中反馈问题或提出建议。
